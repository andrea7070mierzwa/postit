# Post-it 📝

Projeto simples desenvolvido para praticar HTML, CSS e JavaScript.

A ideia foi criar uma página de post-its/lembretes, trabalhando conceitos iniciais de estrutura, estilo e interação com o usuário.

---

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- GitHub Pages

---

## Objetivo

Este projeto faz parte dos meus primeiros estudos em desenvolvimento web.

Foi criado como exercício para praticar:

- organização de arquivos;
- estrutura básica com HTML;
- estilização com CSS;
- primeiros passos com JavaScript;
- publicação no GitHub Pages.
